# YelpCamp

A campground review web application where users can browse campgrounds, add their own, and leave reviews.

> Built while following **The Web Developer Bootcamp** by Colt Steele (Udemy) to practise full-stack web development.

## Features

- User registration, login and logout
- Create, view, edit and delete campgrounds
- Upload campground images (Cloudinary)
- Add and delete reviews with star ratings
- Form validation and flash messages

## Tech Stack

- **Front end:** EJS templates, HTML, CSS, JavaScript
- **Back end:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Image storage:** Cloudinary

## Getting Started

1. Clone the repository.
2. Run `npm install` to install the packages.
3. Create a `.env` file in the project folder and add your own values for the Cloudinary keys, database URL and session secret.
4. Run `node app.js` to start the app.
5. Open http://localhost:3000 in your browser.
